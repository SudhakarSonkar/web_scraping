# 🎶 Tour Events Scraper & Notifier

This project scrapes upcoming tour events from  
[https://programmer100.pythonanywhere.com/tours/](https://programmer100.pythonanywhere.com/tours/)  
and sends you an **email notification** when a new event is announced.  

It also stores previously found events in a **SQLite database** to avoid duplicate alerts.

---

## 🚀 Features
- ✅ Scrapes events (band, city, date) from the target website  
- ✅ Stores events in a local SQLite database (`data.db`)  
- ✅ Sends **detailed email notifications** with event info  
- ✅ Skips duplicates and already saved events  
- ✅ Safe handling of cases like `"No upcoming tours"`
